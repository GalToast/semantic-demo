## 4. Friction patterns documented (this session)

1. **mimo-v2.5 file-size degeneration** — workers stuck generating 700+ line files in one write
   - **Fix:** Use Edit tool or split into separate files
2. **`pi_background_jobs` log-reading trap** — workers stuck polling JSONL logs
   - **Fix:** Steer with "commit anyway" or cancel + manual main-lane commit
3. **Cross-file race conditions** — multiple workers on same file = conflicts
   - **Fix:** Use separate files for parallel work
4. **Stale audit data** — audits can reference state that no longer exists
   - **Fix:** Always verify current state before acting on doc claims
5. **Parallel session force-push drops commits** — rebase can strip local commits
   - **Fix:** Cherry-pick from reflog
6. **Parallel session speed dominance** — 10+ commits in 30 min vs my subagents' 1 commit
   - **Fix:** Decompose into seams that complement (not duplicate) parallel session work
