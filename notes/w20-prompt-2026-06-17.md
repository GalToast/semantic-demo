## Important Operating Rules

- **Subagent model**: Use `openrouter/owl-alpha` (NOT `kilo/openrouter/owl-alpha`) — the kilo gateway is timing out. OpenRouter direct is the recommended route.
- **Always use `git commit --only <pathspec>`** to avoid pulling in parallel session WIP
- **Check `git status --short` before committing** — files marked `M` are owned by the parallel session
- **Multi-line `export { ... }` blocks hide exports from `rg "^export.*\bfn\b"`** — always verify with `rg -B 5 "\bfn\b" file`
- **DO NOT use `pi_background_jobs action: "poll"`** — that action is invalid (use `list|tail|kill|clear` or skip)
- **When subagent hits rate limit**, take over in main lane for small fixes (test assertions, simple reverts)
- **Check `docs/w20-cross-import-map.md` BEFORE trusting it** — Owl-2 found it was wrong about Q1 (loading-ui), Q3 (derivePanelSurface), Q5 (setSemanticDiveMode). Always verify canonical locations by `rg "^export"` rather than trusting the map

## Subagent Friction Pattern (Lessons Learned)

- **Worker stuck after first bash call** → model is too large or rate-limited. Cancel + re-dispatch with smaller model.
- **Worker committed only 1 of 5 expected files** → verify commit with `git show --stat <sha>`, not the commit message.
- **Worker hit `pi_background_jobs action: "poll"` validation error** → keeps retrying the invalid call, burns 5+ minutes. Steer with explicit "do NOT call pi_background_jobs" instruction.
- **Worker finds signature mismatch** → rewire at call sites too (not just imports). Common pattern: legacy `fn(arg)` vs canonical `fn()`.
- **Parallel session force-pushes** → can wipe local commits. Recover with `git cherry-pick <lost-sha>` from reflog.
