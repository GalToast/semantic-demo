## 5. Method notes (recipe lock-in for Phase 3+)

### 5.1 Inline single-image grader (`scripts/vision-grader-inline.mjs`)

**Use this as the default vision-QA harness** from now on. It:

- Sends 1 image per `chat.completions` call (universal-compatible across
  NIM, modelscope, openrouter — NIM's 1-image cap is satisfied).
- Per-model per-surface latency + char-count logs land in
  `tmp/inline-grader-*.log`.
- Per-model grade reports land in `tmp/grade-phase2-inline-<slug>.md`.
- Per-model-token extraction handles both `content` and `reasoning_content`
  (modelscope places the answer in `reasoning_content`, NIM in `content`).
- Both `--mode=single` (default; 7 calls × 1 image) and `--mode=multi`
  (1 call × 7 images — only minimax-m3 accepts this on NIM).
- Provider prefix in router: `--models=provider/<model-id>` where provider
  ∈ {`nvidia`, `modelscope`, `openrouter`, `kilo`, `opencode-zen`} →
  `http://127.0.0.1:8788/<provider>/v1/chat/completions`.

### 5.2 Multi-image as specialty

Only **minimax-m3** (NIM) accepts 7 images in one call (~213 s, 1 round trip).
Use multi-image for that model only; everything else is single-image.

### 5.3 Anti-hallucination checklist when grading reliable picture of pixels

1. Always grade against the _known-clean_ surface (Surface 2 search-coffee)
   first — if a model claims High on it, the model is in over-eager mode and
   its other grades should be discounted.
2. Triangulate: ≥2 reliable graders must agree independently on any
   fix-wave-2 candidate, and ≥1 must describe the same physical pixels.
3. Read the markdown file rather than the JSON summary; the JSON only has
   status + length, not the actual issue description.

### 5.4 Subagent vs inline split

- **agnes-2.0-flash only**: subagent path handles multi-image and the agent
  write-loop → produce report.md directly.
- **Every other vision model**: inline path. NIM VLMs accept images via the
  subagent harness but cannot reliably drive multi-turn agent loops (tool
  use, file write) — the "llama-90b streams `GRADER DONE` char by char with
  0 actual grade" symptom from earlier today is the canonical failure mode.
  Use `scripts/vision-grader-inline.mjs --mode=single` for all non-agnes
  vision models.
