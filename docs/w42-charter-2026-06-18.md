## Goals

### W42-A: Thread Inspector Activation Logic Fix

**Impact:** Real user-facing bug — inspector never activates when self-focus is attempted
**Problem:** `pinThreadNeighbor(519)` silently returns `{active: false, pinned: false}` when `index === focusedIndex`
**Root cause:** Passing the focused index itself (not a neighbor) produces no strand (`segmentCount: 0`)
**Approach:**

1. Add guard in `pinThreadNeighbor(index)` — reject with clear error when `index === focusedIndex`
2. Add `pinFirstAvailableNeighbor()` helper that picks a real neighbor from focus pocket
3. Update `ThreadInspector.svelte` to handle `active === false` state gracefully (show empty-state guidance)
   **Files:** `src/lib/stores/thread-inspector.svelte.ts` or equivalent, `src/components/ThreadInspector.svelte`
   **Risk:** LOW — isolated to thread-inspector surface, already test-guarded (skipped baseline test)

### W42-B: Accessibility (A11y) Sweep

**Impact:** WCAG 2.1 compliance gaps
**Scope (pick 2–3):**

- Keyboard trap in search results (arrow key navigation, Esc to close)

- Screen reader labels for thread connections
- Color contrast audit of secondary text in focus stage
  **Approach:** Per-surface fixes with `tests/a11y-*.mjs` contract additions
  **Risk:** LOW–MED — visual regression risk on focus indicators
