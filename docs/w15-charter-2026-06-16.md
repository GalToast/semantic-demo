## Context

W11–W14 constituted the engine-port + cleanup arc. The codebase migrated from a legacy `js/modules/` imperative kernel to a Svelte 5 reactive engine. W14-T3 (search domain retirement) is the final active ticket in that arc. Once it closes, the project enters a **stabilization phase** before any new feature work.

## W15 Scope

Four tracks, each gated on W14-T3 landing.

### Track 1 — Visual QA Debt Closeout (HIGH priority, ~4-6 hrs)

**Goal:** Eliminate all deferred visual states from `visual-critique-2026-06-12-deferred-states.md`.

**States to verify:**

- `focus-pocket` — focus node selection, pocket constellation placement
- `trail-animation` — thread traversal, color transitions
- `journey-inside` — Inside view, thread neighbor preview
- `arrival-overlay` — strand arrival handoff, overlay fade

**Method:** Headed Playwright pass with per-state screenshot comparison against Round 3 baselines.

**Acceptance:** Each state passes a 7-item contract (canvas visible, DOM IDs present, no console errors, correct body data-attrs, keyboard nav works, URL syncs, responsive layout).

## Risks

1. **W14-T3 delays** — If the parallel session's WIP doesn't close, W15-T3 is blocked. Visual QA and A11y can still proceed.
2. **three-search-animations.ts port** — WebGL code requires human visual QA. Cannot be automated safely. Budget 4-6 hours for this file alone.
3. **CI false positives** — New CI may flag pre-existing warnings as failures. Need grandfathering strategy for warnings.

## Adjacent Seams (W16 candidates)

- **Svelte 5 runes migration** — Some components still use `$state` imperatively instead of reactively. True reactivity unlock would be a refactor arc.
- **Bundle splitting** — `index-CLtCeIot.js` is 1.6MB. Code-splitting by view (galaxy/map/focus) could reduce initial load.
- **SSR / SSG** — Currently client-side only. Pre-rendering the initial state would improve SEO and perceived performance.
