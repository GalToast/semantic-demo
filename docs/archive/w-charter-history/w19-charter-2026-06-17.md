| File                              | Internal js/modules/ importers (BLOCKERS)                                                                                          |

**Correct recon command for future:** `rg "from.*['\"](\\.\\./)*js/modules" js/modules` BEFORE deleting anything.

**Verified deletions are safe only after Wave 3.** Running `git rm` on any of these 6 files today would break the build.

## Wave 3 plan — internal cross-import rewiring

Goal: every `js/modules/→js/modules/` import in the 6 files above is replaced with the corresponding `@lib/*` canonical, so the 6 files become leaf modules with zero inbound cross-imports.

### Step 1: Audit exact import edges

```bash
cd /path/to/semantic-explorer
rg -n "from.*js/modules" js/modules/thread-inspector.ts js/modules/journey-thread-settler.ts js/modules/journey-focus-ui.ts js/modules/lifecycle-modes.ts js/modules/lifecycle-reset.ts js/modules/url-state.ts js/modules/journey-webgl.ts js/modules/journey-route-trace.ts js/modules/journey-arrival-handoff.ts js/modules/journey-semantic-overlay.ts js/modules/journey-compass-controller.ts
```

For each importer file, identify which `js/modules/*` symbol it imports, and map to the `@lib/*` canonical (if it exists) or to a NEW `@lib/` module (if it doesn't).

### Step 2: Build the cross-import map

Before touching any of the 6 "dead" files, document in a `tmp/w20-cross-import-map.md` file:

- For each `js/modules/X` symbol imported by a 6-file consumer, the target `@lib/*` path
- Whether the target is an existing canonical or a new module to be created
- Order of rewiring (leaf-first to avoid breaking intermediate states)

### Step 3: Leaf-first rewire

Pick the file with the LEAST cross-imports first. In rough order:

1. `js/modules/url-state.ts` (no js/modules consumers in the table — likely safe)
2. `js/modules/loading-ui.ts` (only 1 cross-importer: view-controller.ts)
3. `js/modules/lifecycle-modes.ts` and `js/modules/lifecycle-reset.ts` (1-2 cross-importers each)
4. `js/modules/journey-thread-settler.ts`, `js/modules/thread-inspector.ts`, `js/modules/journey-focus-ui.ts` (3 cross-importers among them — pick order carefully)
5. `js/modules/journey-webgl.ts` + `js/modules/journey-semantic-overlay.ts` + `js/modules/journey-route-trace.ts` + `js/modules/journey-arrival-handoff.ts` (journey consumer chain — wire all to `@lib/journey/*` or extract new canonicals)
6. `js/modules/map-state.ts` and `js/modules/view-controller.ts` (cross-import each other — handle as a pair)
7. `js/modules/journey.ts` and `js/modules/lifecycle.ts` and `js/modules/composition-state.ts` (the 3 largest blockers)

For each rewire:

- Stage and verify with `npx svelte-check` before commit
- Use `git commit --only <pathspec>` to avoid parallel session drift
