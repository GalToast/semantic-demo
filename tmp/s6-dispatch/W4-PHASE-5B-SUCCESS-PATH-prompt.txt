## What "success" means for this test

- HTTP response HAS at least one `x-router-*` header
- The response body is NON-EMPTY and contains the alternative carrier's
  success payload
- The latency is consistent with primary-then-alternative 2-hop (e.g.,
  ~1-3 seconds, declining if the alternative carrier is faster)
- If diagnostic headers aren't present, document the gap (overlay either
  failed to dispatch to alternative, or overlay succeeded but key-router
  didn't preserve headers — see Phase-5C patch).
