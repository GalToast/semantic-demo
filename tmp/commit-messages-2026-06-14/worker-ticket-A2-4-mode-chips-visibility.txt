## Background

The a11y audit (2026-06-14) found:
- **A2-4 (HIGH):** When the user switches to Search or Focus mode, the `#banner` header collapses to `width: 0; height: 0`, hiding the mode chips from keyboard navigation. There are no keyboard shortcuts to switch modes, so keyboard users have no way to return to Overview.

**WCAG:** 2.1.1 Keyboard (Level A), 2.4.7 Focus Visible (Level AA)

**Evidence:**
```
Search mode: banner computed size = 0×0
Mode chips: not reachable via Tab
Global keyboard shortcuts: Arrow, Home, End, +/- (no mode switch)
Escape key: clears search input, does NOT exit search mode
```
