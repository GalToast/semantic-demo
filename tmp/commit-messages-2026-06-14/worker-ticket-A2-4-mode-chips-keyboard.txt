## Background

The a11y audit (2026-06-14) found:
- **A2-4 (HIGH):** When switching to Search or Focus mode, the `#banner` header collapses to `width: 0; height: 0`, hiding mode chips from keyboard navigation. There are no keyboard shortcuts to switch modes, so keyboard users are trapped.

**Evidence:**
```
Search mode: banner computed size = 0×0
Mode chips: not reachable via Tab
Global keyboard shortcuts: Arrow, Home, End, +/- (no mode switch)
Escape key: clears search input, does NOT exit search mode
```

- **A2-5 (MEDIUM):** Mode chips use `role="radiogroup"` + `role="radio"` + `aria-checked` (correct semantics) but are navigated with Tab (incorrect keyboard pattern). Per WAI-ARIA, radiogroups should use arrow keys.

**WCAG:** 2.1.1 Keyboard (Level A), 4.1.2 Name, Role, Value (Level A)

### Step 2: Fix mode chip visibility (A2-4)

The banner header is hidden in non-idle modes. Options:
1. **Keep the mode chips always visible** — move them out of the banner into a fixed-position element that's always reachable
2. **Add keyboard shortcuts** — e.g., `Ctrl+1` through `Ctrl+6` for each mode, or `Escape` to return to Overview
3. **Show a compact mode switcher** in non-idle modes — a minimal toolbar that appears when the full header is hidden

**Recommended approach:** Option 3 — show a compact mode chip bar when in Search/Focus/Inside modes. This is the least disruptive change and maintains the current layout.

The compact bar should:
- Be positioned at the top-center (where the full header was)
- Show only the mode chip icons (not full labels)
- Be keyboard-navigable
- Have proper ARIA (same radiogroup semantics)

### Step 3: Implement arrow key navigation (A2-5)

Within the radiogroup, replace Tab navigation with arrow keys:
1. Only the active radio button gets `tabindex="0"`
2. All other radios get `tabindex="-1"`
3. Left/ArrowUp selects the previous mode
4. Right/ArrowDown selects the next mode
5. Home selects the first mode (Overview)
6. End selects the last mode (Map)

**Pattern reference:** WAI-ARIA Radio Group Pattern
https://www.w3.org/WAI/ARIA/apg/patterns/radio/
