However, they're navigated with Tab (one Tab per chip) instead of arrow keys. Per WAI-ARIA, radiogroups should use roving tabindex with arrow keys for intra-group navigation.

### Step 2: Implement roving tabindex

Follow the WAI-ARIA radiogroup pattern:

1. Only the active (checked) radio should have `tabindex="0"`
2. All other radios should have `tabindex="-1"`
3. Arrow key handlers on the radiogroup container:
   - ArrowRight/ArrowDown: Move to next radio
   - ArrowLeft/ArrowUp: Move to previous radio
   - Home: Move to first radio
   - End: Move to last radio
4. When focus moves, update `tabindex` on the old and new radios
5. When a radio receives focus, it should also be selected (activate the mode)

**Implementation approach:**
- Add `tabindex={isActive(m.id) ? 0 : -1}` to each mode chip
- Add `onkeydown` handler to the radiogroup container
- On ArrowRight/ArrowDown: find next mode, set it as active, move focus
- On ArrowLeft/ArrowUp: find previous mode, set it as active, move focus
- On Home: move to first mode
- On End: move to last mode
