## Goal

Add `aria-keyshortcuts` to the canvas element to declare available keyboard shortcuts for screen readers.

## Background

The a11y audit (2026-06-14) found:
- **A2-7 (MEDIUM):** The canvas `role="application"` responds to Arrow keys, Home, End, +/- for camera control, but doesn't declare these via `aria-keyshortcuts`.

**Current canvas attributes:**
```
role="application"
aria-label="Semantic business visualization of Montgomery County businesses. Use arrow keys to navigate."
tabindex="0"
```

**Missing:** `aria-keyshortcuts`

**WCAG:** 4.1.2 Name, Role, Value (Level A)

## Specific steps

### Step 1: Read the Canvas component

Read `src/components/Canvas.svelte`. Find where the canvas element is created and its attributes are set.

### Step 2: Add aria-keyshortcuts

Add `aria-keyshortcuts` to the canvas element listing the supported shortcuts:
```
aria-keyshortcuts="ArrowLeft ArrowRight ArrowUp ArrowDown Home End"
```

Note: `+` and `-` are not standard key shortcut names. Use `Equal` (for `+=`) and `Minus` (for `-`) if needed, or just omit them — the arrow keys and Home/End are the most important to declare.
