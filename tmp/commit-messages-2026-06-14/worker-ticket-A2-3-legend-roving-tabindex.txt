### Step 2: Implement roving tabindex

The legend category list should behave like a `role="radiogroup"` (single-select) or `role="listbox"` (multi-select) pattern:

1. Only the first legend button (or the currently active/filtered button) should have `tabindex="0"`
2. All other legend buttons should have `tabindex="-1"`
3. Arrow key handlers:
   - ArrowDown/ArrowRight: Move focus to next button
   - ArrowUp/ArrowLeft: Move focus to previous button
   - Home: Move focus to first button
   - End: Move focus to last button
4. When focus moves, update `tabindex` on the old and new buttons

**Implementation approach:**
- Add a `let activeLegendIndex = $state(0)` to track which button has focus
- Add `tabindex={i === activeLegendIndex ? 0 : -1}` to each button
- Add `onkeydown` handler to the container (or each button) that manages arrow key navigation
- On focus (via `onfocus` or `onmouseenter`), update `activeLegendIndex`
