### Step 2: Implement roving tabindex

The pattern:
1. Only the FIRST button (or the currently active/filtering button) gets `tabindex="0"`.
2. All other buttons get `tabindex="-1"`.
3. Add `onkeydown` handler for ArrowDown/ArrowRight (next), ArrowUp/ArrowLeft (previous), Home (first), End (last).
4. On arrow key press: prevent default, set current button to `tabindex="-1"`, set target button to `tabindex="0"`, call `target.focus()`.

**Example pattern:**
```svelte
<script>
  let focusIndex = $state(0);
  
  function handleKeydown(event, index) {
    const buttons = /* get all button elements */;
    let next = index;
    
    switch (event.key) {
      case 'ArrowDown':
      case 'ArrowRight':
        event.preventDefault();
        next = (index + 1) % buttons.length;
        break;
      case 'ArrowUp':
      case 'ArrowLeft':
        event.preventDefault();
        next = (index - 1 + buttons.length) % buttons.length;
        break;
      case 'Home':
        event.preventDefault();
        next = 0;
        break;
      case 'End':
        event.preventDefault();
        next = buttons.length - 1;
        break;
      default:
        return;
    }
    
    focusIndex = next;
    buttons[next]?.focus();
  }
</script>

{#each entries as entry, i}
  <button
    tabindex={i === focusIndex ? 0 : -1}
    onkeydown={(e) => handleKeydown(e, i)}
    ...
  >
```

**Important considerations:**
- When the legend opens/closes, reset `focusIndex` to 0 or the active filter.
- When a filter is active, set `focusIndex` to the active button's index.
- The existing `aria-pressed` on each button should be preserved.
- Don't break the existing click handler.
