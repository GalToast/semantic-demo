### Step 2: Debug and fix the toggle

The panel DOM exists but isn't becoming visible. Possible causes:

2. JavaScript event handler not wired up
3. CSS specificity issue keeping `visibility: hidden`

Find the toggle handler and ensure:

- The CSS transitions `visibility` and `opacity` when the class is present
- `aria-hidden` is updated to `"false"` when visible
- A close button or Escape key dismisses the panel
- Focus is trapped in the panel when open (or at least focus moves to it)
